Quintus | Fri, 20 Feb 2015 09:03:21 UTC 

Chris Jacobsen <…9@y…> writes:

> First, I have split the theme song discussion at
> http://forum.secretchronicles.de/topics/122 in order to separate
> Ashburry's post from Johan's post and prevent confusion.

Thanks.

> Second, we need to contact Johan about the sublicensing on his songs

Before we do so we should probably discuss how to handle the title
song. I’ve not come to a conclusion about it yet and I’d like to see
some discussion. I have suggested asking for a sublicensing right as
this will allow us to definitely outline who can use it and who not.

However, placing restrictions on the title song may seem inconsistent
with the rest of the game, which we want to have CC licensing for. We
could also just ask for a CC-BY 4.0 license, then the title song would
be in one line with all the other assets. Which of course would also
allow other people to use it.

Having it as a separately licensed asset might be a difficulty for
distributors even though we allow them to include it. This is something
I’d like to have a distributor’s opinion on.

> "Johan, You had submitted a theme song and credits song at
> http://forum.secretchronicles.de/topics/122 (under the user id
> jobromedia) and had given us permission to use them in our game, "The
> Secret Chronicles of Dr. M". It turns out we need separate permission
> in order to technically allow the game to be posted in distributions
> (ie Linux distributions) with these songs and to allow the songs to be
> used in forks of the game if necessary.  Of course, it may not always
> make sense to allow other games to use the songs -- if everyone
> started using these for a title theme or credits theme, the songs
> would cease to be Secret Chronicles themes. The only way to deal with
> the complex set of scenarios that arise is to have the ability to
> sublicense these songs to other people. This would allow us to
> analyze a new situation if it arises and grant permission if it is
> warranted.  If you are fine with this, simply state, "I grant the
> ability to sublicense the title and credits themes at
> http://forum.secretchronicles.de/topics/122 that I posted as
> jobromedia to the Secret Chronicles team.""

The general structure of this is good, but it might upset Johan that we
don’t even talk about his monetary requests. On the other hand, one
shouldn’t get out on the sleeping dogs (does English have that
saying?). I don’t want to upset him in such a way that he doesn’t even
answer.

> I'm sure some more improvements can be made to this draft. Once we
> figure them out, we can contact him.  I've had a fairly good email
> relationship with him, so I'd be glad to send it. Otherwise we could
> have the project lead, Quintus, send it.

I’d be fine with either.
