Okay, I'll check them out as I get some time over the next week or so.

Our programming tasks are listed at Secretchronicles/TSC (along with other tasks such as art tasks and music tasks).

I may talk to Quintus about breaking "Art and Music" into "Art" and "Music" task categories.

The big focus for programming now is bug fixing for release 2.0.  These are signified with the "Bug" label in github.  Bugs needed in order to make release 2.0 acceptable are also marked as "release 2.0" for the milestone.  Anything with release 2.0 on the label is needed in order to complete the release faster.

The Release 2.0 branch in github corresponds to changes slated to go into the release (we have a feature freeze for code changes for this).  The devel branch is where new features go, which will be in subsequent versions of the game.
