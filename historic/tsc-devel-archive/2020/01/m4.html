Thank you very much that you took the time to compile and review the new 
beta2. This is very kind of you and helps the promotion of TSC. Glancing 
over the page, I've only catched one error. The page says that TSC is 
written using SDL and OpenGL. This was true of TSC 2.0.0, but it has 
changed with 2.1.0. We have replaced SDL with SFML¹, i.e. TSC is now 
written using SFML and OpenGL. You probably got that information from 
our main website at secretchronicles.org, but once once 2.1.0 has 
reached stable state we are going to change that on the website.

>or the latest beta2

>https://linuxreviews.org/The_Secret_Chronicles_of_Dr._M._2.1.0_beta_2_Is_Released


You might want to take a look at the level editor. It's UI has been 
improved quite a bit compared to 2.0.0.

The new Larry and Doom Larry are explosive enemies. If Alex jumps on 
them, they fuse and finally explode after a few seconds. Doom Larry 
kills Alex instantly, Larry only deals normal damage. The new 
"sauer2_15" level features some Larries; you can load it via the "Level" 
tab in the "Start" menu.

Pre-compiled versions of the beta2 will follow in a few days when our 
Windows developer (xet7) has found the time to compile them. When that 
has happened, the beta2 will be announced properly via the 
secretchronicles.org website as was the case with the beta1.

Also, thanks for highlighting our need for level authors.

  -quintus

¹ https://www.sfml-dev.org/
